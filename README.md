# 달고나 뽑기의 달인 — 도형 테두리를 긁어 안 깨고 뽑기

## 실행
- `index.html` 더블클릭(file://, 빌드 없음, 외부 의존은 Pretendard CDN 한 줄뿐). 폰: 같은 와이파이에서 정적 서버로 열기.
- 판정 단위 검증: `node tools/sim.js` / 화면·키보드·멀티터치·반응형: `node tools/qa.js [--shots]`

## 규칙 (정본: `src/game/engine.js`, 상수 `config.js`, 논리 좌표 600×600 — 화면 크기와 무관)
- 조작: 방향키 이동(대각선 정규화·관성 없음) / SPACE 누르는 동안 긁기(느려져서 정밀) / ENTER 뽑기 / R 재시작. 모바일: 8방향 버튼 + [긁기] + [뽑기], 멀티터치.
- 바늘끝↔경로 최단거리 d: `≤ON(8)` 정확히 긁음(진행률 증가, 중복 없음) / 밖이면 균열 증가(멀수록·도형 안쪽일수록·같은 곳 반복일수록 큼). 균열 100 = 파손. 선 이탈 = ON 안에서 EXIT(11) 밖으로 나간 횟수.
- 진행률 ≥ 92% 에서 [뽑기] 활성. 점수 = 정확도 45 + 균열 20 + 시간 15 + 끝까지 긁은 정도 20 − 이탈(회당 1, 최대 10).

## 모양·에셋
- `assets/{circle,triangle,star,umbrella}.jpg`(사진, 600×600, 원판 중심 300,300·반지름 ≈246~250)를 달고나 본체로 쓴다.
- 판정 경로 `src/game/paths.js`는 사진의 음각 홈에서 `node tools/extract.js`로 추출(이미지 px 좌표). 사진을 바꾸면 재추출 후 `screenshot/path_*.png` 오버레이로 확인.
- 사진을 못 불러오면 `shapes.js`의 코드 도형 + 절차적 달고나로 대체(경로가 사진과 다르므로 assets 를 함께 둘 것). 모양 추가 = 사진 + SEEDS(extract.js) + `shapes.js` META/ORDER 한 줄.

## 화면 규격
- 사과 깎기(261014) 토큰 복제: 앱 430px·콘텐츠 320px·비주얼 320×200. 메인·게임 방법·모양 선택·결과의 주요 버튼 y 동일(메인 [게임 시작] 기준), 게임 화면은 메인이 쓰는 세로 범위(비주얼 상단 ~ [게임 시작] 하단) 안에 HUD(위)·조작부(아래)를 둔다. QA 가 실측.

## 결과 · 도전장 · 파손 (2026-11-16 추가)
- 결과 화면은 사과 깎기와 같은 구조(이미지 → 제목 → 점수 → 등급 한 줄 → `정확도 · 균열 · 소요 시간` → [친구에게 도전장 보내기] / [다른 모양 도전][다시 뽑기] → `@ccojik.dh`).
- 도전장(`src/game/battle.js`): 사과·썰기와 같은 방식 — 링크 해시 `#battle/v1.<base64url JSON>`에 기록(닉네임·모양·성공/실패·점수·정확도·균열·이탈·시간·진행도·판 시드·파손 지점)만 담는다(서버 없음). 받는 쪽은 같은 시드로 친구의 최종 모습을 다시 그리고 → [도전 시작](같은 모양) → 대결 결과(점수 VS 점수·승패) → [다시 붙기]/[내 결과 자세히 보기]. 공개 주소는 `config.js DG.SHARE.URL`(비우면 지금 주소; file:// 은 이 PC 에서만 열림 안내).
- 파손(`view.js planFracture`): 응력 지점(파손 위치·플레이 중 균열·윤곽 꼭짓점)에 작은 파편이 몰린 불균형 보로노이 분할 + 비주기 노이즈 경계(거친 직선형/완만한 곡선형). 실금 → 일부만 분리(분리/느슨/붙어 있음 3상태). 조각이 비운 자리는 아무것도 안 칠해 알파 0 — 아래 배경이 그대로 보인다.
- 검증: `node tools/qa.js` [5] 4모양×성공/실패 알파·위치/크기·반투명 면 없음, [6] 도전장 링크 생성→열기→도전→대결 결과. (헤드리스에서 `navigator.share` 는 끈다 — Windows 공유 시트가 열리며 Chrome 이 죽는다.)

## 직접 만들기 (직접 그린 도안)
- 선택 카드 4번째 `직접 만들기`(난이도 `모름`) → [시작하기] → `도안을 그려주세요`(빈 달고나 `assets/empty.png` 위에 그린다, 원판 밖은 가장자리로 붙음) → [완료] → 플레이.
- 그린 모양은 스무딩·확대·중앙 정렬 없이 그대로 쓴다. 여러 획은 가까운 끝점끼리 이어 한 줄로, 시작점↔끝점은 직선으로 닫는다. 중복점만 정리(정수 좌표, 최대 160점).
- 플레이에서는 같은 빈 달고나 에셋에 홈(눌러 찍은 음영)을 새겨 그린다. 판정·균열·뽑기는 세모/별/우산과 동일(`DG.setCustom(pts)` → `DG.SHAPES.custom`).
- 도전장 링크에는 도안 path 가 `c` 로 담긴다. 예외 문구: 도안을 먼저 그려주세요 / 조금 더 길게 그려주세요 / 도안이 너무 복잡해요.
